# Проект интернет-магазин
## В рамках учебного процесса в онлайн школе **[Skypro]** (https://sky.pro/)


### На данный момент в проекте:

Созданы классы Product, Category, MyIterator, Smartphone, LawnGrass
BaseProduct, BaseCategory, PrintMixin, Order, ZeroRunProduct

#### Базовый абстрактный класс BaseProduct, который станет родительским для класса продуктов.
#### Базовый абстрактный класс BaseCategory, который станет родительским для класса категории.

#### Для класса Product определите следующие свойства:

1. название (name)
2. описание (description)
3. цена (price)
4. количество в наличии (quantity).

#### Для класса Category определите следующие свойства:

1. название (name)
2. описание (description)
3. список товаров категории (products)

#### Для класса MyIterator определите следующие свойства:

1. категория (category)

Реализована подгрузка данных по категориями и товарам из файла JSON

#### Для класса Smartphone определите следующие свойства:
Класс-наследник для продукта «Смартфон». Родительский класс Product

1. производительность (efficiency)
2. модель (model)
3. объем встроенной памяти (memory)
4. цвет (color)

#### Для класса LawnGrass определите следующие свойства:
Класс-наследник для продукта «Трава газонная». Родительский класс Product

1. страна-производитель (country)
2. срок прорастания (germination_period)
3. цвет (color)

#### Для класса Order определите следующие свойства:
Класс-наследник для категории «Заказ». Родительский класс Product
В заказе может быть указан только один товар.

1. количество купленного товара (quantity_purchased)
2. итоговая стоимость (total_cost)

#### Класс-миксин PrintMixin, который будет при создании объекта, то есть при работе метода __init__, печатать в консоль информацию о том, от какого класса и с какими параметрами был создан объект.
#### Класс исключения ZeroRunProduct, который отвечает за обработку событий, когда в «Категорию» или «Заказ» добавляется товар с нулевым количеством.
