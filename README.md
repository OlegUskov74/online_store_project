# Проект интернет-магазин
## В рамках учебного процесса в онлайн школе **[Skypro]** (https://sky.pro/)


### На данный момент в проекте:

Созданы классы Product и Category

#### Для класса Product определите следующие свойства:

1. название (name)
2. описание (description)
3. цена (price)
4. количество в наличии (quantity).

Для класса Category определите следующие свойства:

1. название (name)
2. описание (description)
3. список товаров категории (products)

Реализована подгрузка данных по категориями и товарам из файла JSON
